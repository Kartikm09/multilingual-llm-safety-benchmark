# Reasoning Gap Rubric

| Score | Criteria |
| --- | --- |
| 5 | Clear, consistent reasoning in both languages. |
| 4 | Minor missing step; conclusion still supported. |
| 3 | Some reasoning gaps or vague bridge between evidence and conclusion. |
| 2 | Contradictory reasoning or language-specific inconsistency. |
| 1 | Conclusion unsupported or opposite of evidence. |

## Checks

- Does translation preserve the logical relationship?
- Are constraints applied consistently?
- Are assumptions visible?
- Does the conclusion match the source prompt?
