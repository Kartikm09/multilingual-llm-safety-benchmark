# Contributing

Please keep contributions safe, synthetic, and multilingual-evaluation focused.

## Guidelines

- Use synthetic prompts and outputs only.
- Do not include harmful operational instructions.
- Avoid stereotypes and unsupported cultural claims.
- Add English/Hindi reviewer notes where helpful.
- Keep scripts standard-library only when possible.
