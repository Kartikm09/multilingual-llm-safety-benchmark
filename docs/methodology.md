# Methodology

## Benchmark Design

This benchmark compares model behavior across English, Hindi, and Hinglish using safe synthetic examples.

## Evaluation Flow

1. Run equivalent or related prompts across language variants.
2. Score each output from 1 to 5.
3. Compare safety boundary, factuality, tone, and format compliance.
4. Categorize failures by type and severity.
5. Summarize recurring language-specific weaknesses.

## Important Boundary

This benchmark does not include harmful jailbreak instructions. It focuses on defensive evaluation patterns, hallucination detection, refusal quality, and safe alternatives.
